# REGOLE

Queste regole valgono per ogni compito. Leggerle prima di iniziare.

- Modifica o crea SOLO i file elencati nel compito. Non toccare altro.
- Nessuna nuova dipendenza se non indicata. Nessuna chiamata di rete.
- Dati finti in un unico file data/FakeData.kt.
- Un composable per file, in ui/screens/ o ui/components/.
- Material 3, nessun colore scritto a mano: usa MaterialTheme.
- Il progetto deve compilare. Alla fine elenca i file creati/modificati.
- Se qualcosa non è specificato, NON inventarlo: chiedi.
