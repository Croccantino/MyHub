# MyHub

App Android per monitorare e controllare un server che gira sul mio PC Windows, con un database SQL, raggiungibile da ovunque tramite Tailscale.

## Obiettivo

- Server con database sempre accessibile, anche da fuori casa
- Collegarlo, in alcuni casi, ai siti su GitHub Pages per smettere di usare Firebase
- Per ora solo i miei dispositivi più il PC (nessun utente esterno)
- App Android sviluppata con Android Studio, codice scritto con OpenCode

## Architettura

```
[App MyHub] --HTTP + Bearer token--> [Agente FastAPI] --> [PostgreSQL]
     (telefono, Tailscale)            (PC Windows)
```

- **Rete:** Tailscale (alternativa valutata: Cloudflare Tunnel)
- **Server:** il mio PC Windows
- **Database:** PostgreSQL
- **Agente:** Python + FastAPI, unico punto d'ingresso. L'app non parla mai direttamente con il database
- **App:** Kotlin, Jetpack Compose, Material 3
- **Progetti OpenCode separati:** uno per il server, uno per l'app Android
- **Controllo remoto:** Desktop remoto di Windows

## Agente server

File: `agente/main.py`, `agente/schema.sql`, `agente/requirements.txt`, `agente/.env.example`

Endpoint (tutti con header `Authorization: Bearer <token>`):

|Metodo|Percorso|Cosa fa|
|---|---|---|
|GET|`/health`|Test connessione. Risposta `{"ok": true, "db": true/false}`|
|GET|`/stato`|CPU, RAM, uptime|
|GET|`/disco`|Spazio dei dischi in `DISK_PATHS`|
|GET|`/accessi`|Registro accessi, filtri `limit`, `metodo`, `esito`, `da`|
|POST|`/accessi`|Registra un accesso|

Tabella `accessi`: `id`, `ts` (timestamptz), `utente`, `metodo` (rdp, ssh, api, db, app), `ip` (inet), `esito` (ok, fallito), `dettagli`.

Avvio: `uvicorn main:app --env-file .env --host <IP Tailscale> --port 8000`

Variabili `.env`: `DATABASE_URL`, `API_TOKEN`, `DISK_PATHS`.

## Interfaccia (da bozzetti a mano)

- **Logo (DB con logo Windows):** è un pulsante che apre il menu laterale
- **Menu laterale:**
    - Dati (icona grafico): dati di accesso al server
    - Preferenze (icona righe impilate): connessioni ai server
    - Impostazioni (ingranaggio): opzioni dell'app
- **Barra inferiore:** aiuto (?), ricarica, home, connessione (spina + wifi)
- **Home:** tile stato desktop (statistiche PC), disco, controllo remoto, dispositivi connessi, terminale
- Il controllo di Tailscale sta nella schermata Stato desktop, non nell'aiuto

### Schermata Preferenze

- Titolo "Preference", logo in alto a sinistra
- Lista dei desktop (nomi tipo `DESKTOP-...`), ognuno con maniglia di trascinamento a sinistra e pallini verde/rosso a destra
- Pallini **automatici**: verde = acceso, rosso = spento
- Il desktop più in alto è quello prioritario, si riordina trascinando
- Pulsante a tutta larghezza "+ add a new desktop" in fondo
- Scheda di modifica: nome, indirizzo Tailscale, porta, token, servizi (Desktop remoto, SSH, database), "Testa connessione"

### Schermata Dati (Access)

- Titolo "Access", timer 00:00:00 in alto a destra = uptime del PC
- Due grafici a linee: lettura e scrittura del disco
- Sezione "accessi al PC": righe con IP, data, ora, in lista scorrevole
- Toccando una riga si apre una scheda di dettaglio

## Sicurezza

- Token e password cifrati con Android Keystore, mai in chiaro
- HTTP in chiaro ammesso solo verso indirizzi Tailscale (`network_security_config`), perché il traffico dentro Tailscale è già cifrato
- Emulatore Android inutile per i test: non vede Tailscale, usare il telefono vero con l'app Tailscale
- Niente pulsante per spegnere Tailscale dall'app (taglierebbe il collegamento da solo); semmai "riavvia Tailscale"
- Dettaglio accessi sospetti: dati realistici (IP, posizione stimata a livello di città, tentativi falliti, azioni nei log) e pulsante "Blocca IP" sul firewall. Telefono ed email di chi entra non sono ottenibili
